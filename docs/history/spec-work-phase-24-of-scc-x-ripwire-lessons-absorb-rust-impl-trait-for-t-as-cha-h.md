## Goal

Phase 24 of SCC x Ripwire lessons: absorb Rust impl Trait for T as CHA heritage. Ripwire rustImplVisitNode emits inherit Extends (derived T, base Trait). Extract simple-ident trait bases onto T, persist on CLASS/INTERFACE entity attributes like other heritage, name trait methods Trait.m so unique-class-like CHA can pin. Unique typed x: T and Cls.m() pin T.m or the unique hitting trait default/required method. Two traits defining the same method at one level stay unresolved. Inherent impl methods still win over trait CHA. No Go embedding (Ripwire captureBases does not include Go). No C++ extractors. Keep four context levels, 10 MCP tools, and the production ranker.
